# Support

Thanks for using **AOBench** — the role-aware, permission-enforced benchmark for
evaluating AI agents that operate HPC systems. Here is how to get help.

## Documentation first

Most questions are answered in the docs and README:

- **Documentation site:** <https://mskazemi.com/aobench/>
- **README (quickstart, examples, FAQ):** <https://github.com/MSKazemi/aobench/blob/main/README.md>
- **CLI reference:** <https://github.com/MSKazemi/aobench/blob/main/docs/reference/commands.md>
- **Programmatic access (REST / MCP):** <https://github.com/MSKazemi/aobench/blob/main/docs/guides/programmatic-access.md>

## Asking a question

- **General questions, ideas, and "how do I…?"** → open a
  [GitHub Discussion](https://github.com/MSKazemi/aobench/discussions).
- **Bug reports and concrete feature requests** → open a
  [GitHub Issue](https://github.com/MSKazemi/aobench/issues) using the templates.

When reporting a problem, please include:

- Your AOBench version (`aobench --version`) and Python version.
- The exact command you ran and the full output / traceback.
- The adapter, task ID, and environment ID involved, if relevant.
